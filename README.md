## 👋 About

I'm a builder with a product mindset. I start from a real problem, ship a working version fast, and iterate until it's something people actually want to use. I work end to end: interface, backend, data, and the automation that ties it together.

More and more of my work involves AI: agents, tooling and workflows that take repetitive work off people's plates.

## 🧭 What I build

- **Web products** — fast, responsive, production-minded front ends with clean UX
- **APIs & backends** — simple, reliable services that products are built on
- **AI agents & automation** — tools, skills and MCP integrations that make agents genuinely useful
